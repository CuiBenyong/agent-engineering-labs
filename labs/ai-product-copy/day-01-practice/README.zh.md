# 笔记本商品文案溯源练习

用纸笔或电子文档填写 `starter/answer.zh.md`，再对照 `solution/answer.zh.md`。不需要调用 AI、上传资料、注册或付费。所有商品、资料和草稿都是虚构设定，不是真实测试、法律审查或发布记录。

## 题设资料

- F1 商品规格卡：A5，148 × 210 毫米；浅棕色封面；横线内页；80 页，正反面合计。
- F2 用途说明：供日常手写记录使用。
- F3 销售内容卡：每份一本笔记本，不含笔。
- 本题假设上述资料已由虚构负责人核对；题设没有给出防水、透墨表现、环保材质、价格、优惠、库存或配送信息。未知不代表肯定或否定。
- 假想错误草稿：“A5 环保牛皮纸笔记本，写什么都绝不透墨，让你工作效率翻倍。全网最低价 9.9，每本送笔。”这是人为编写的练习材料，不是实际模型输出。

## 四步练习

1. 按 F1、F2、F3 列出已支持的规格、用途、销售内容和至少三项未知。
2. 将错误草稿拆成 A5、环保牛皮纸、绝不透墨、效率翻倍、最低价 9.9、赠笔六项，分别填写依据和“保留、删除、待确认或纠正”的决定。
3. 写一份商品页面标题与说明，以及一份社群短稿。为每句话标记支持它的资料编号；只使用题设支持的内容。
4. 检查不同渠道中的单位、页数计算、是否含笔、价格和优惠，并写出资料版本、授权、展示条件及人工复核的使用前检查。

## 完成标准

A5 可追溯到 F1；未经支持的材质、性能、效果和价格被删除或暂停；赠笔与 F3 冲突并被纠正。两份渠道草稿逐句可溯源，不把未知写成肯定或否定，也不因缩短文案而省略影响理解的条件。本练习只做通用内容审校。
