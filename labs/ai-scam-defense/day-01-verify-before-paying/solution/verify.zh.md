# 示例答案：先核实，再付款

这是一个**虚构**练习。这里给出一种站得住的写法，措辞可以不同。

## 各案例的红旗

| 红旗                   | C1                 | C2                   | C3                       | C4     |
| ---------------------- | ------------------ | -------------------- | ------------------------ | ------ |
| 紧急                   | 有——“今晚”         | 有——“12 小时内”      | 有——账户“已被盗”         | 无     |
| 保密                   | 有——“别告诉妈妈”   | 无                   | 暗示——要在这通电话里办完 | 无     |
| 难以追回的付款方式     | 有——礼品卡         | 通过链接填银行卡信息 | 有——转入“安全账户”       | 无     |
| 索要验证码或银行卡信息 | 有——念出卡号       | 有——在网站上填卡号   | 有——一次性验证码         | 无     |
| Grace 无法核实的渠道   | 有——两个陌生号码   | 有——消息里的链接     | 有——搜索广告里的号码     | 无     |
| **风险**               | **高**（5 个红旗） | **高**（4 个红旗）   | **高**（5 个红旗）       | **低** |

## 停、查、告诉

| 案例 | 停                               | 查                                                                                       | 告诉                                                                                           |
| ---- | -------------------------------- | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| C1   | 挂断。不买礼品卡，不念任何号码。 | 用存好的号码打给 Theo；没人接就打给 Mei。约定过暗号就问暗号。                            | 告诉 Mei。举报这次企图（例如美国可用 ReportFraud.ftc.gov 或 IC3；中国大陆已被骗及时拨 110 报警，96110 可咨询或举报线索）。 |
| C2   | 不点链接，不填银行卡信息。       | 打开快递公司的官方 App，或自己输入官网地址，查有没有包裹。                               | 删除短信；通过手机或运营商的举报功能把它报为垃圾或钓鱼信息。                                   |
| C3   | 挂断。不念验证码，不转钱。       | 用银行卡背面印的号码或银行官方 App 联系银行，询问那笔扣款。                              | 通过官方电话告诉银行发生了什么；告诉 Mei；举报那个假号码。                                     |
| C4   | 没有明显高风险请求。             | 存好的号码不证明身份；照片可能包含隐私，有疑问时用独立途径核实。 | 不需要举报。                                                                                   |

## AI 判断审阅

| 说法                                     | 问题                                                               | 改正后的表述                                      |
| ---------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------- |
| “C1 听起来确实是 Theo”                   | 声音可以克隆；听着像不等于身份成立                                 | 声音证明不了什么；用存好的号码打给 Theo           |
| “律师还报了案件编号”                     | 案件编号谁都能编；它来自同一个未经核实的渠道                       | 来电者提供的细节不算核实                          |
| “用礼品卡交保释金挺快的”                 | 没有哪个法院或警局用礼品卡收保释金；礼品卡难以追回                 | 电话里要求用礼品卡付款是红旗，不是付款方式        |
| “C2 只要 1.99 美元，付了也没多大风险”    | 小额费用是诱饵，目的是通过链接骗取银行卡信息                       | 不要通过链接付款；在官方 App 或自己输入的网址里查 |
| “C3 是安全的，因为号码是 Grace 自己查的” | 她查到的是搜索广告，不是银行；真正的银行从不索要验证码或“安全账户” | 高风险；用卡背面的号码或官方 App                  |
| “C4 很可疑，因为它是短信”                | 过度怀疑：存好的号码、不要钱、不紧急、不保密                       | 低风险不等于安全；存号可被冒用，有疑问时独立核实        |

## 家庭核实计划（一页）

**暗号规则：**由 Grace、Mei、Theo 当面约定；绝不写进家庭群；不用生日、宠物名或街道名；一旦被用过就换掉。

**核实时打给谁：**Theo——存好的号码，备用联系人 Mei；Mei——存好的号码，备用联系人 Theo；银行——Grace 银行卡背面印的号码或官方 App。

**无论谁要求都绝不做：**替电话里的人买礼品卡；念出一次性验证码；把钱转到“安全账户”；安装来电者要求的 App；通过消息里的链接付款。

**觉得不对劲时：**挂断——这永远不算失礼；用存好的号码回拨；告诉一位家人。

**钱或信息已经给出去之后：**立刻用卡背面的号码联系银行，请求处理转账和银行卡；及时报案、告诉家人；能否止付或追回无法保证。被骗的人不会被责怪。

演练一次：Mei 扮演催促的来电者，Grace 练习说“我回头打给你”、挂断，再拨打 Theo 存好的号码。
