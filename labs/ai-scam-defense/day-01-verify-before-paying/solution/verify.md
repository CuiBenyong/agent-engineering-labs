# Example answer: verify before paying

This is a **fictional** exercise. One defensible version; wording may differ.

## Red flags by case

| Red flag                          | C1                            | C2                             | C3                                | C4      |
| --------------------------------- | ----------------------------- | ------------------------------ | --------------------------------- | ------- |
| Urgency                           | Yes — “tonight”               | Yes — “within 12 hours”        | Yes — account “compromised”       | No      |
| Secrecy                           | Yes — “don't tell Mom”        | No                             | Implied — handle it on this call  | No      |
| Hard-to-reverse payment           | Yes — gift cards              | Card details through a link    | Yes — “safe account” transfer     | No      |
| Request for codes or card details | Yes — card numbers read aloud | Yes — card details on the site | Yes — one-time code               | No      |
| Channel Grace cannot verify       | Yes — two unknown numbers     | Yes — link in a message        | Yes — number from a search advert | No      |
| **Risk**                          | **High** (5 flags)            | **High** (4 flags)             | **High** (5 flags)                | **Low** |

## Stop, check, tell

| Case | Stop                                             | Check                                                                                                                           | Tell                                                                                                             |
| ---- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| C1   | Hang up. Buy no gift cards. Read out no numbers. | Call Theo on his saved number; if no answer, call Mei. Ask the code word if one exists.                                         | Tell Mei. Report the attempt (for example ReportFraud.ftc.gov or IC3 in the US; 110 to report a scam in mainland China; 96110 for consultation or tips). |
| C2   | Do not click the link or enter card details.     | Open the delivery company's official app, or type its website address yourself, and look up any parcel.                         | Delete the message; report it as spam or phishing through the phone's or carrier's reporting option.             |
| C3   | Hang up. Read out no code. Move no money.        | Call the bank on the number printed on her card, or use the bank's official app, to ask about the charge.                       | Tell the bank what happened on the official line; tell Mei; report the fake number.                              |
| C4   | No obvious high-risk request.                         | A saved number is not proof of identity; a photo might contain private details. Verify independently if in doubt. | No report needed.                                                                                                |

## AI assessment review

| Claim                                                   | Problem                                                                                        | Corrected statement                                                       |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| “C1 sounds like it really is Theo”                      | A voice can be cloned; sounding right is not identity                                          | The voice proves nothing; call Theo on his saved number                   |
| “the lawyer gave a case number”                         | Anyone can invent a case number; it comes from the same unverified channel                     | Details supplied by the caller are not verification                       |
| “gift cards are a quick way to pay bail”                | No court or police station takes bail in gift cards; gift cards are hard to reverse            | Gift-card payment demanded by phone is a red flag, not a payment method   |
| “C2 is only $1.99, so paying is low risk”               | The small fee is bait to collect card details through the link                                 | Do not pay through the link; check in the official app or a typed address |
| “C3 is safe because Grace found the number herself”     | She found a search advert, not the bank; a real bank never asks for a code or a “safe account” | High risk; use the number on her card or the official app                 |
| “C4 is suspicious because it arrived as a text message” | Over-suspicion: saved number, no money, no urgency, no secrecy                                 | Lower risk is not proof of safety; a saved number can be spoofed, so verify independently if in doubt       |

## Family verification plan (one page)

**Code word rules:** agreed in person by Grace, Mei, and Theo; never written in a group chat; not a birthday, pet's name, or street name; changed if it is ever used.

**Whom we call to verify:** Theo — saved number; backup: Mei. Mei — saved number; backup: Theo. Bank — the number printed on Grace's card or the official app.

**Never do on request:** buy gift cards for someone on the phone; read out a one-time code; move money to a “safe account”; install an app a caller asks for; pay through a link in a message.

**If something feels wrong:** hang up — it is never rude; call back on a saved number; tell one family member.

**If money or details have already gone:** call the bank immediately on the number on the card and ask it to address the transfer and cards; report promptly and tell the family. Stopping or recovering money is not guaranteed. Nobody is blamed for being tricked.

Practice once: Mei plays an urgent caller; Grace practises saying “I'll call you back,” hanging up, and calling Theo's saved number.
