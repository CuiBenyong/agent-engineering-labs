# D2 实验：独立核实演练

[English](README.md) · [中文练习模板](starter/independent-verification.zh.md) · [中文参考答案](solution/independent-verification.zh.md)

本练习使用 D1 的虚构人物 Grace、女儿 Mei 和外孙 Theo。Grace 生活在美国。四个案例的内容只用于纸笔演练，不改变 D1 的原有结果；后面的中国大陆家庭场景是另一个虚构假设。**不需要实际联系机构、拨号、付款、下载软件、点击或复制可疑链接，也不要上传身份信息、验证码或真实材料。** 不需要 AI；如使用 AI，仅输入自行改写的虚构信息。遇到真实事件不必等完成练习才求助。

如果可能有人身紧急危险，立即通过可信途径联系当地紧急服务，不等待核实暗号、家庭回复或完成表格。下面的案例练习不要求进行任何真实呼叫。

## 四个案例

- **C1 亲友求助：**21:40，一个陌生号码打来，声音像 Theo。对方声称出了车祸、人在警局，要求不要告诉妈妈；稍后另一个自称律师的人要求今晚购买 **3,000 美元礼品卡**，并念出卡号。
- **C2 包裹短信：**短信声称包裹无法投递，要求 12 小时内支付 **1.99 美元**重新派送费，附有一个仿冒快递网站的链接；Grace 不记得有包裹在路上。练习不提供链接。
- **C3 假客服：**Grace 发现一笔不认识的扣款，拨打搜索广告中显示的“银行电话”。对方声称账户被盗，要求将 **12,000 美元**转入“安全账户”，并念出一次性验证码。
- **C4 低风险对照：**一条显示来自 Grace 已存 Theo 号码的消息，请她发送菜谱照片；没有观察到付款、验证码、保密或截止时间要求。已存号码可能被冒用，照片也可能带有隐私信息。

## 步骤

1. 打开 [starter/independent-verification.zh.md](starter/independent-verification.zh.md)。给 C1–C4 各写一行：**直接观察**、**未核实说法或未知事项**、**下一步**。例如，“对方声称出了事故”是听到的说法；事故本身是否发生仍未知。独立渠道证实一件事，也不代表整段对话都是真的。
2. 为 C1、C2、C3 分别写出一个中断动作和一条独立核实路径：已存亲友联系方式及备用亲友、原本使用的官方应用或独立核实的快递公司渠道、银行卡背面号码或独立核实的银行官方渠道。不要使用对方提供的号码、消息里的链接或搜索广告号码。为 C4 写出相对低风险的理由、隐私检查和不确定时的核实办法。
3. 在模板中处理**中国大陆另一个假设**：母亲接到声音像女儿的来电，对方说路上出了事故，要求保密并立即转账。写出若可能有人身紧急危险怎么办、如何同时停止付款和联系亲友、110、120 与 96110 的不同用途。不要填写任何私人号码。
4. 自己或与同伴口头演练“停、查、告诉”。没有同伴也可以独立完成；核对下面清单后再看参考答案。多种合理答案都可接受。

## 验收条件

- [ ] C1–C4 每行都有具体观察、未核实说法或未知事项、下一步；不把来电声音、已存号码、暗号或低风险当成安全或身份的证明。
- [ ] C1、C2、C3 各有中断动作和独立渠道；短信不点链接，假客服不念验证码、不转入“安全账户”，并仍通过银行核查原有扣款。
- [ ] C4 说明相对低风险不等于安全，留意照片隐私；不确定时独立核实。
- [ ] 可能有人身紧急危险时立即联系当地紧急服务，不机械等待；中国大陆需警方处置时用 **110**、需医疗急救时用 **120**；**96110** 用于反诈预警劝阻、防骗咨询或涉诈线索举报，不替代紧急报警。
- [ ] 没有真实联系、拨号、转账、下载、点可疑链接或上传真实身份信息和验证码。
