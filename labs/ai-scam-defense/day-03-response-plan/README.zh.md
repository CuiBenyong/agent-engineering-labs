# D3 实验：写一张应对卡

[English](README.md) · [中文练习模板](starter/response-plan.zh.md) · [中文参考答案](solution/response-plan.zh.md)

这是纸笔练习：三个事件是从 Grace 案例延伸出的**互相独立的虚构假设**，不会改变 D1 的 C1–C4 结果。练习不代表真实事故、真实付款或已完成的处置。不要实际联系机构、拨号、付款、登录账户、安装或下载软件、点击可疑链接，也不要上传身份信息、验证码或真实材料；不需要 AI。真实事件发生时不必完成练习才求助。

## 三种假设

- **A：验证码已说出。**在 C3 的另一种虚构发展中，Grace 把一个一次性验证码告诉未核实的“客服”，随后警觉；目前没有看到转账，但并不知道验证码是否被使用。练习中没有实际验证码。
- **B：付款已完成。**在独立的另一种虚构发展中，Grace 向“安全账户”转出 12,000 美元后怀疑被骗。这只是想象的练习设定，没有真实转账或处理结果，也不意味着 A 或 C 发生。
- **C：安装陌生远程控制软件。**在第三个独立假设中，Grace 听从对方要求安装陌生远程控制软件并开启屏幕共享，不知道对方看到了什么。没有实际安装或设备操作，也不意味着 A 或 B 发生。

## 步骤

1. 打开 [starter/response-plan.zh.md](starter/response-plan.zh.md)。对 A、B、C **分别**写：已知和未知、立即停止什么、如何通过自己已知或独立核实的官方渠道尽快联系银行或支付机构、如何联系当地警方、可信的人可以怎样帮忙。
2. A 写明已说出验证码但未见转账仍需及时报告，不再次念验证码；B 写明付款方式、可询问止付或撤回等选项，以及无法保证结果；C 写明停止屏幕共享与对方连接、优先用另一台可信设备联系机构和警方，设备恢复遵循机构或可信专业人员指导，不等设备修好再联系金融机构。
3. 列出安全可得的记录、不能为收集证据耽误的求助，以及对“先交费用就能追回”的应对。再写一张简短应对卡并口头演练，独自完成也可以。
4. 自查下方条件，再与[参考答案](solution/response-plan.zh.md)比较。不同地区、机构和事件的具体做法可能不同，其他安全、合理的答案也可以。

## 验收条件

- [ ] 识别三个情境是互不相关的虚构假设；有人可能面临紧急人身危险时，立即通过可信途径联系当地紧急服务，不等核实、截图或家人回复。
- [ ] 停止继续提供信息或付款；尽快用已知或独立核实的官方渠道联系银行或支付机构和当地警方，按当地实际情况及时或并行，不以一方答复为另一方的前提。
- [ ] A 不因暂未看到转账而认定安全；B 询问止付、撤回或其他处理，不保证止付或追回；C 停止共享及对方连接，优先用另一台可信设备求助，按机构或可信专业人员指导恢复。
- [ ] 在安全且不耽误求助时保留适当记录；说明可信的人如何协助；拒绝先付费“追损”和再次交出验证码或远控权限。
- [ ] 没有真实联系、拨号、转账、设备安装或下载、点击可疑链接，或上传身份信息、验证码和真实材料。

其他地区按所在地实际情况使用独立核实的警方、紧急服务和金融机构官方渠道。任何机构均不能保证成功止付或追回。
