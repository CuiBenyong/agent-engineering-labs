## 删完之后发生了什么

- 用示例任务在 Plan Mode 下跑，计划里出现了「先跑 `pnpm vitest run test/todos.test.ts` 确认基线」和「不引入新依赖，用 zod strict」——两条规矩都被遵守。
- 初稿版本下同一个任务，Claude 曾顺手 `pnpm add joi`，并跑了全量 `pnpm test` 等了 40 秒——就是这两条被目录说明和废话淹没了。
- 「提交前运行 lint 与测试」这条留在了「完成的判据」里，但 D4 会把它做成 Stop hook：文字是建议，hook 才是门禁。
