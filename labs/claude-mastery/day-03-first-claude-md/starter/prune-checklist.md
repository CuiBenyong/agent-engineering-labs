# /init 初稿逐行自检表

> 用法：把 /init 生成的 CLAUDE.md 每一行（或每一段）抄到左栏，右边三列勾一个，最后一列写理由。理由写不出来的行，默认删。

## 常见判定

| 初稿里常见的一行                                | 判定                  | 为什么                                                                        |
| ----------------------------------------------- | --------------------- | ----------------------------------------------------------------------------- |
| 「本项目使用 TypeScript + Express」             | 删                    | 读 package.json 就知道                                                        |
| 「src/routes/ 存放路由，src/lib/ 存放工具函数」 | 删                    | 目录名已经说明了；除非命名有反直觉之处                                        |
| 「运行 `pnpm test` 执行测试」                   | 改                    | 脚本名能看到；改成「只跑单文件 `pnpm vitest run <file>`，全量很慢」才有信息量 |
| 「遵循 ESLint 规则」                            | 删                    | 它本来就会                                                                    |
| 「提交前运行 lint 与测试」                      | 留（并考虑做成 hook） | 猜不到；但「每次必须」的动作靠文字不可靠，D4 会讲 hook                        |
| 「不要修改 migrations/ 目录」                   | 留                    | 猜不到，且违反代价高                                                          |
| 「当前 sprint 目标是……」                        | 删                    | 经常变，会过期                                                                |

## 删完后自检

- [ ] 总行数 ≤ 60
- [ ] 每段都有内容，四段一个不缺
- [ ] 全文搜「干净」「最佳实践」「注意」零命中
- [ ] 每条规矩都是「不能做什么」而不是「可以做什么」
- [ ] 「完成的判据」是一条可以运行的命令
