# 长输入模板（文件袋）

> 用法：材料多于一份、或任何一份材料超过一屏时用它。标签名可以自己起，但要成对、语义清楚、前后一致。
> 顺序：材料 → 指令 → 示例。指令一定放在材料之后。

## 模板

```text
<context>
> TODO：一两句话交代背景：这是什么项目、材料从哪来。
</context>

<（材料一的标签名）>
> TODO：第一份材料原文。例：现有代码、需求文档、schema。
</（材料一的标签名）>

<（材料二的标签名）>
> TODO：第二份材料原文。
</（材料二的标签名）>

<instructions>
> TODO：编号列出要做的事。每条一个动作，写清「改哪里、改成什么、不要动什么」。
> TODO：要求回答时引用标签名，例：「先引用 current_code 里有问题的那一行」。
</instructions>

<example>
> TODO：一个输入 → 期望输出的例子。没有就删掉这一段，不要硬凑。
</example>
```

## 自检

- [ ] 顶层标签 3–6 个，每个都成对闭合
- [ ] `<instructions>` 在所有材料之后
- [ ] 材料里如果含 Markdown 或 XML，标签名没有和它撞
