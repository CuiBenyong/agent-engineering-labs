# system prompt 模板（名片）

> 用法：填好后放进 Messages API 的 `system` 字段，或 Claude Code 的 `--append-system-prompt`。
> 三段顺序固定：角色 → 边界 → 输出风格。全文不超过 300 字，不含会变的信息。

## 模板

```text
你是（角色）：
> TODO：一句话。是谁、负责什么项目、用什么技术栈。不要写「乐于助人的 AI 助手」这种空话。

边界：
> TODO：写 2–4 条禁止项，不写能力清单。例：只改哪些目录、不引入哪些依赖、不确定时先提问。

输出风格：
> TODO：写 2–3 条。语言、注释语言、先解释再给代码还是反过来、长度上限。
```

## 自检

- [ ] 全文搜「今天」「当前用户」「现在时间」零命中
- [ ] 每一条边界都是「不能做什么」，不是「能做什么」
- [ ] 删掉任何一条，Claude 都会更容易出错；删不掉的才留
