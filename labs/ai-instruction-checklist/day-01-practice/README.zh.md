# 借还说明的条件清单

下列说明为虚构练习，不是实际图书馆规则；没有真实账号、书本、借阅、归还或消息发送。

- **S1**：如果打算借书，先在自助台查看这本书是否可借。
- **S2**：如果显示可借，把读者卡放到读卡区，按屏幕提示进行借出操作；仅在屏幕显示借出成功后，记下屏幕显示的归还日期。
- **S3**：如果显示不可借，或借出操作显示失败，先询问工作人员；得到指引前不要继续自助操作。
- **S4**：归还前如果发现书有损坏，先告诉工作人员，按其指引处理；不要自行修补。
- **S5**：如果书没有损坏，把书交到服务台归还。
- **S6**：借出成功后，若想保留借阅凭证，可以保存；不要求必须保存。

填写 `starter/answer.zh.md`：按顺序写动作、来源、条件、必须或可选、适用性及执行状态。将不可借和操作失败分成两行；未判断的条件不能写成不适用，未执行或不适用不能写成已完成。再推演两种假设：可借且借出成功；不可借或操作失败。归还日期的具体值、借期长度和工作人员回复时间均未给出，不能补造。

验收标准：保留“可借后操作”“成功后记录日期”；任一 S3 触发时先询问且得到指引前不继续自助；损坏与无损坏分别处理；保存凭证是成功后本人可选；假设和实际状态分开，所有真实动作仍未执行。纸笔即可完成。
