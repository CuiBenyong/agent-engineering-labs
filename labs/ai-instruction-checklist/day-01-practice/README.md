# Conditional borrowing and return checklist

These instructions are fictional practice, not a real library's rules. No real account, book, borrowing, return or message is involved.

- **S1**: If you intend to borrow a book, first check at the self-service terminal whether that book is available to borrow.
- **S2**: If it shows available, place the library card in the reader area and follow the screen prompts to attempt the borrowing operation. Only after the screen shows borrowing succeeded, record the return date shown on the screen.
- **S3**: If it shows unavailable, or the borrowing operation shows failure, first ask a staff member. Do not continue self-service operations before receiving guidance.
- **S4**: Before returning, if you notice damage to the book, first tell a staff member and follow their guidance; do not repair it yourself.
- **S5**: If the book is not damaged, hand it to the service desk to return it.
- **S6**: After borrowing succeeds, if you want to keep a borrowing receipt, you may save it; saving it is not required.
