# MCP 服务端安全检查清单（待填）

> 对象：**你自己写的那个服务端**。本课默认是 D4 的 `labs/mcp-7days/day-04-streamable-http-deploy/solution`，
> 换成你自己的项目更好——这份清单的价值在于填的是真东西。
>
> 每一条填四格：
>
> - **现状**：`是` / `否` / `不适用`。选「不适用」必须在证据里说清为什么。
> - **证据**：一行命令、一段输出、或者一个 `文件:行号`。**不接受「应该做了」「印象中有」**。
> - **风险**：没做到的话，攻击者具体能干什么。写不出来说明这一条你还没看懂。
> - **计划**：修 / 不修 / 以后修，以及判断依据。
>
> 填的顺序建议从 A 到 G。A、B、C 是协议要求的硬项，D 是今天的重点，E 只有代理型服务端才需要，
> F 是你作为客户端作者的义务，G 是出事之后唯一能救你的东西。
