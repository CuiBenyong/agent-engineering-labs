# 虚构画面替代文字练习

用纸笔或电子文档填写 `starter/answer.zh.md`，再对照 `solution/answer.zh.md`。事实卡描述的是不存在的练习图；没有真实人物、图片、模型识图或读屏测试，不需要上传或生成图片。

## 虚构事实卡

- F1：一个人坐在靠窗的木桌前，双手扶着一本打开的书。
- F2：一只蓝色杯子放在书的右侧。
- F3：画面没有可辨认的文字。
- F4：题设没有提供人物姓名、年龄、职业、身份或心情。

两种情境使用同一张虚构图：A 是阅读空间文章，图像要补充人物、书与窗边桌子的关系；B 是桌面摆放说明，图像要表达蓝色杯子在书右侧。两种情境的附近文字都没有给出各自要表达的关系。

假想错误稿：“一位开心的退休老师在家阅读故事，桌上的海报写着读书会报名。”这句话人为编造，用于找出无依据的身份、情绪、地点和文字，不是实际模型结果。

## 四步练习

1. 根据事实卡列出已给出的对象、动作和位置，以及不得猜测的未知。
2. 为 A、B 各写一条简短文字，说明每条选择的信息与事实编号；不必机械描述所有细节。
3. 对照错误稿圈出无依据的年龄、职业、情绪、地点、故事和海报文字；写出如何改正。
4. 记录真实使用时需要核对的上下文、图中文字、隐私权限和实际辅助技术呈现；标明本题没有真实页面或测试。

## 完成标准

A 说明人与书在窗边桌前的关系；B 说明蓝色杯子在书右侧；两句都不猜人物身份或不存在的文字。能解释为什么用途不同会影响重点，知道纯装饰、功能图和复杂图需要按实际环境分别判断，不把纸面描述说成已完成无障碍测试。

参考：[W3C 图片无障碍教程](https://www.w3.org/WAI/tutorials/images/)及[替代文字决策树](https://www.w3.org/WAI/tutorials/images/decision-tree/)。
