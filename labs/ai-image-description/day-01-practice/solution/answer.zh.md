# 一种参考答案：两种替代文字

本答案依据虚构事实卡完成，没有真实图片、模型识图或读屏测试。其他忠于事实并适合具体上下文的表述也可以。

## 1. 虚构事实与未知

- F1：一个人坐在靠窗的木桌前，双手扶着一本打开的书。
- F2：一只蓝色杯子放在书的右侧。
- F3：画面没有可辨认的文字。
- F4：题设没有提供人物姓名、年龄、职业、身份或心情。

## 2. 两种上下文

情境 A 是阅读空间文章，需补充人物和书在窗边桌前的关系，依据 F1：

> 一个人坐在窗边桌前，双手扶着一本打开的书。

情境 B 是桌面摆放说明，需表达蓝色杯子在书右侧，依据 F1、F2：

> 一只蓝色杯子放在打开的书右侧。

两句都不猜人物和文字；A 强调人物与书，B 强调杯子与书的位置。是否加入其他细节仍要看真实用途与附近文字，不存在适合所有场景的固定句子。

## 3. 审核假想错误稿

- 题设确实有人、书和桌子，但没有说人物是退休老师、心情开心、地点在家，或书的内容是故事。
- F3 说明没有可辨认文字，不能编造海报和“读书会报名”。根据 A 或 B 使用上面的对应描述。
- 可复制请求：只依据给定虚构事实，为阅读空间文章写一条替代文字；强调人物、书和窗边桌子的关系，不猜人物姓名、年龄、职业、身份或情绪，不编造图中文字，并列出对应事实供人工核对。

## 4. 实际使用前的检查

- 看图像的具体用途、周围文字是否已经提供相关信息，以及描述是否遗漏该用途需要的内容。
- 纯装饰、功能图和复杂信息图要分别判断：可能需要避免重复、说明操作或提供额外文字信息；具体做法以实际环境与适用指南核对。
- 真实图像上传前检查素材和人物隐私与许可；不确定时不上传。本练习只有虚构文字。
- 根据实际应用确认文字能否被相应辅助技术取得，必要时结合实际使用者反馈；没有测试就记“待检查”。
- 本题没有真实图片、模型识图、读屏测试或无障碍认证。
