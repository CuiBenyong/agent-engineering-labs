# 阅读插图修改与版本比较

用纸笔或电子文档填写 `starter/answer.zh.md`，再与 `solution/answer.zh.md` 比较。两份版本都是以下文字设定，没有真实图片，也没有进行工具测试。练习无需生成、上传、注册或付费。

## 给定情景

- 用途：为虚构读书会的群公告规划示意插图，右上角需给两行短标题留空间。
- V1：柔和水彩风格；窗户在左边，暖光照进来；木桌上打开的书在左下，蓝色杯子在书的右侧。植物叶子伸进右上角；书的下缘被画面边缘切掉，右上角留白不足。
- 本轮目标：书完整地位于左下，书下缘和画面边框之间有一点空间；右上角约四分之一的区域清空。
- 假想 V2：书仍在左下且完整，下缘留空，右上角约四分之一清空；杯子仍在书的右侧但变红，光线变冷；左窗和水彩风格假设没变。没有提供 V3。

## 四步练习

1. 记下 V1 中至少三项要保留的内容和两项问题，用文字或草图标出位置。
2. 写一条能复制的请求，只处理书的位置和右上角留白；交代保留内容及如何判断结果。
3. 按每项修改与保留条件比较 V1 和假想 V2；决定可否作为最终图，并写一条以 V2 为基础的下一轮请求。不要填写未经提供的 V3 结果。
4. 自定停止条件，写出上传前以及公开使用前的授权、隐私、服务条件与标识检查。

## 完成标准

请求说清两个可观察的变化，也写明要保留的蓝杯、暖光和画面要素；比较记录同时发现两项改善和杯色、光线两项变化；能解释再修改后为何要重查整图。纸上结论标为假想，不声称已经看到或使用图片。
