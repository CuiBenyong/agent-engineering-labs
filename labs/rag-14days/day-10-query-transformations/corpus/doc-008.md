# 数据导出与备份

## 谁能导出

只有工作区管理员可以发起全量数据导出。普通成员只能导出自己有权限访问的单篇文档或单个任务板，访客不能导出任何内容。

## 导出流程

管理员在「工作区设置 - 数据导出」发起任务，系统会在后台打包，打包完成后通过站内消息和邮件发送下载链接。**导出包的下载链接有效期是 72 小时**，过期后需要重新发起导出任务。

同一个工作区在 24 小时内最多发起 3 次全量导出，这是为了避免打包任务把存储带宽占满。

## 导出内容与格式

导出包是一个 ZIP 文件，内部按模块分目录：

- `documents/`：每篇文档一个 Markdown 文件，附件放在同名目录里
- `tasks/`：每个任务板一个 JSON 文件，包含任务、评论、变更历史
- `messages/`：每个频道一个 JSON 文件，按时间正序
- `files/`：网盘文件按原目录结构原样保留

消息模块的导出不包含已撤回的消息，也不包含其他成员的私有频道，即使发起人是管理员也一样。

## 备份

公有云版本由平台侧统一做备份，备份周期是每日全量加每小时增量，备份保留 35 天。备份用于整体灾难恢复，不提供按单个文件或单条消息粒度的恢复服务。

私有化部署版本的备份由客户自行负责，云梯科技只提供备份脚本与恢复文档，不承担数据丢失责任。
