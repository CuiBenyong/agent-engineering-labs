# D12 实验：带自我反思与多跳能力的检索 Agent，以及它与固定流程的指标和成本对比

> 目标：把检索包成一个带完整描述的工具，接进一个最小 Agent 循环，让它在材料不够时自己改写查询再查一轮；
> 再给循环装上三道刹车，最后在 D8 那份 20 题标准答案集上，把它和「查一次就答」的固定流程摆在一起，
> 指标、调用次数、延迟三笔账一起报。

## 你会学到

- 把混合检索（BM25 + 向量 → 倒数排名融合 → 重排）包成一个工具，工具描述按「范围 / 该用 / 不该用 / 查询怎么写」四段写
- 加一个检索侧的相关性自评，不合格就自动改写查询重试（**这跟 D6 的生成侧拒答是两层，不要混**）
- 分清两类检索失败：「根本没捞到」（要多跳）和「捞到了却被自己的门槛扔了」（要降级放宽），修法相反
- 用 `q06` 这道多跳题看清循环的实际轨迹：第一跳只查到「须平台组组长审批」，第二跳顺着这个指代查到「组长是周敏」
- 给循环装三道刹车：最大轮数、累计材料 token 预算、重复查询检测，并各构造一个会触发它的用例
- 在 20 题上对比固定流程与 Agentic 流程，看清这 25 个点的多跳召回是用多少次额外调用换来的

## 验收标准

1. `MOCK=1 pnpm start` 跑完，第七段「验收」九项全部 ✅
2. 第二段轨迹里 `q06` 跑了两轮：第一轮自评是 `follow-up` 并点出「平台组组长」这个指代，第二轮查到 `doc-014` 后判 `sufficient`，最终上下文里 `doc-019` 与 `doc-014` 都在
3. 第三段里无答案的 `q19` 被刹车拦住（停止原因是 `duplicate-query` 而不是 `sufficient`），把材料预算压到 400 token 再跑一次，停止原因变成 `token-budget`
4. 第四段把门槛收紧成「只认向量路」之后，降级放宽救回 2 道多跳题（`q17` / `q18`），「放宽过」那一列能看出是哪几道
5. 第五段的表里 multi 档召回率高于固定流程、single 档没有退步；第六段逐题表里能看出是哪一道多跳题被多查的那一轮救了回来

## MOCK 说明（先读这一段再看数字）

`MOCK=1` 下有两个替身，它们的边界必须说清楚：

- **哈希向量**（D2 定的唯一实现）保留字面重合度，所以向量检索的行为接近关键词检索。它验证的是代码路径，不是检索效果。
- **规则自评替身**（`createRuleAssessor`）用三条规则代替模型：要素覆盖率、答案槽位是否填上、桥接短语提取。
  其中槽位正则带着这份语料的行文习惯（「平台组组长是周敏」这种写法），换一份语料要重写；
  改写出来的查询也是词元碎片（你会在第三段看到「网页 页端 端支 浏览」这种东西），真模型会写成人话。
  **所以 MOCK 下的多跳成功率不代表真实模型的多跳成功率**，可信的是轮数、调用次数、停止原因这些**结构性**的东西。

**被 mock 掉的只有「谁来判断」，没有「怎么循环」。** 循环控制、三道刹车、多跳的上下文预算分配
全都是真实代码，`MOCK=1` 和真实模式跑的是同一份——今天要教的正是这一部分。

延迟同理：MOCK 下不走网络，第四段的耗时只反映本机计算量，**不代表线上延迟**。
线上真实的延迟结构是「每多一轮 = 一次检索 + 一次自评调用」，可信的是调用次数那一行。

## 常见坑

1. **多跳成功了，命中却没变。** 第二跳明明检索到了 `doc-014`，上下文里却没有它——因为把所有轮的候选混在一起按名次装，第一跳的材料字面重合度更高，600 token 被它占满了。上下文预算必须**按跳轮转分配**（`packHops`），这是练习 3 的全部内容。把它改回 `hops.flat()` 跑一次，你会亲眼看到 `q06` 从命中变回未命中。
2. **重复查询检测要放在检索之前。** 放在后面等于白花一次检索调用才发现自己在原地打转。判重要对查询做归一化（只看词的集合），否则「主备切换 审批」和「审批 主备切换」会被当成两个不同的查询，循环照转不误。
3. **默认那三道闸不是每道都会在这份语料上触发。** 最大轮数 4、材料预算 3000 token，而每轮只读约 600 token，所以四轮跑满也到不了预算线——预算这道闸要压到 400 token 才现形（第三段最后一行就是这么演示的）。**闸门装了不等于验过，每一道都要构造一个用例把它踩响。**
4. **两类失败别用错药。** 「根本没捞到」（`q06` 的 `doc-014` 在候选池里一次都没出现）只能靠多跳换查询词，放宽门槛毫无用处；「捞到了被门槛扔了」（严格门槛下 `q17` 的 `doc-021` 排第 2、余弦 0.187）只能靠降级放宽，跳多少跳都没用。自评把类型判错就会用反药：实测里 `q07` 在严格门槛下被判成「查到半路」，去跳了一个跳不通的下一跳，最后 `give-up`——这个反例保留在输出里，不要「修」掉它。

5. **别拿 `none` 类题的拒答率去夸 Agentic。** 固定流程量的是「有没有候选过门槛」，Agentic 量的是「循环结束时自评有没有说够了」，两者是同一件事在不同位置的表现，不是同一个公式。报这一行时必须把口径一起说，否则就是在拿两把不同的尺子比长短。
