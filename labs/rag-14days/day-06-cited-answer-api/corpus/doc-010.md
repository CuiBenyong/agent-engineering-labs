# 集成与开放 API 概览

## 认证方式

开放 API 支持两种认证：个人访问令牌和 OAuth 2.0 应用授权。个人访问令牌适合脚本和内部工具，令牌默认有效期 90 天，创建时可以选择更短的有效期但不能更长。OAuth 应用适合要分发给多个团队使用的第三方集成。

令牌只在创建时完整展示一次，之后只能看到前 8 位。令牌泄露后应立即在设置页吊销，吊销即时生效。

## 限流策略

**开放 API 的默认限流是每个令牌每分钟 60 次请求。** 超出限流会返回 429，响应头里带 `Retry-After`，单位是秒。批量接口按一次请求计数，不按其中的条目数计数。

企业版客户可以申请提高限流上限，上限调整属于线上配置变更，**必须提交变更评审，走《变更评审规范》里定义的流程**，不能由客户成功经理直接改。申请时需要说明预计峰值、业务场景和降级方案。

## Webhook

支持对任务创建、任务状态变更、文档发布、成员加入四类事件配置 Webhook。每个工作区最多配置 20 个 Webhook 地址。

推送失败会按 1 分钟、5 分钟、30 分钟三次重试，三次都失败则丢弃该事件并在集成日志里记一条错误。Webhook 请求带签名头，接收方应校验签名后再处理。

## 沙箱环境

企业版客户可以申请一个沙箱工作区用于集成联调，沙箱环境的数据每 30 天清空一次，且不参与限流统计。沙箱的接口地址与生产不同，切换时只需要改基础地址。
