# 常见问题：任务通知没收到

## 先确认这四件事

1. 你是不是这个任务的负责人或被指定人。云梯协作只对负责人和被指定人推送任务通知，旁观者不会收到。
2. 你的免打扰是不是开着。免打扰期间推送会被抑制，但站内红点仍然会累加。
3. 该频道的通知渠道设置是不是被你调成了「不推送」。默认设置是「被指定时才推送」。
4. 移动设备的系统通知权限是不是被关掉了。

## 截止时间到了却没提醒

这是最常见的误解：**任务的截止时间本身不会自动提醒**，必须在任务详情里显式添加提醒。可以设置到期前 1 小时、1 天或 3 天，一个任务最多 3 条。

任务被重新指派后，原负责人的提醒会自动取消，新负责人需要自己重新添加。很多「没收到提醒」的工单最后都定位到了这一条。

## 收到了但延迟很久

站内通知是实时的。移动推送依赖各平台的推送服务，国内 Android 设备如果没有厂商推送通道，应用被系统清理后可能延迟或丢失。请把云梯协作加入系统的电池优化白名单。

邮件摘要不是实时的，每天上午 9 点固定发送一次，没有实时选项。

## 群发通知太多想减少

可以按频道单独设置通知渠道，也可以把不关心的公开频道设置为「仅红点」。管理员无法代成员批量修改通知设置，这是每个人自己的偏好。

## 需要我们排查时

请提供任务链接、你的账号邮箱、预期收到通知的大致时间。我们可以查到该条通知有没有被投递以及投递结果。
