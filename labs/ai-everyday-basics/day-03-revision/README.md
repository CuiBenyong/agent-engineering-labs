# D3: Revise one issue at a time

Practice two separate follow-ups and inspect the resulting text. The case is fictional: Lin has one hour on Friday; public event material is organized; next week's plans were discussed with a colleague but not decided; the event venue is unconfirmed.

Start with this **fictional incorrect draft**, not an actual assistant response:

> Version A: I organized public event material, confirmed the event venue, and finalized next week's plans with a colleague.

There are two status errors. You may complete the whole lab on paper or use an available tool with only the fictional material. You do not need to pay, provide real personal information, contact anyone, or send a real message.

## Steps

1. Copy [the starter](starter/exercise.md), or write its headings on paper. Save A and identify both errors.
2. Write one follow-up that targets the venue only. Save a full B: write a labeled paper simulation, or record the actual revision if you chose a tool.
3. Quote A's and B's venue wording. Record whether that target passed and whether B as a whole is ready. Keep any plan error on the issue list.
4. Write a separate follow-up about next week's plans. Save the full C, again marking it as simulated or actual.
5. Quote B's and C's plan wording and judge that target. Review C from beginning to end against all source statuses, and look for invented dates, owners, promises, or completed actions.
6. If any check fails, record it as unresolved and name the next correction. Then compare with [one possible solution](solution/exercise.md).

## Acceptance

- Full A, B, C and both focused follow-ups are retained in order; the route is labeled accurately.
- Each round quotes the target before and after, gives a pass or not-passed judgment with a reason, and separates target success from whole-draft readiness.
- The final review covers organized material, discussed-but-undecided plans, the unconfirmed venue, and unsupported additions. Any remaining error has a next step.
- Different actual answers or paper revisions are acceptable; judge the words you saved, not the example.
