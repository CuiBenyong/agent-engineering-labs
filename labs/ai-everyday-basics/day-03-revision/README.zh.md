# D3：一次修改一项

练习两条分开的追问，并检查实际保存的正文。案例均为虚构：小林周五有一小时；公开活动资料已整理；下周安排与同事讨论过但未确定；活动场地尚未确认。

从这份**虚构错误草稿**开始；它不是实际助手的回答：

> 版本 A：我整理了公开活动资料，已确认活动场地，并与同事确定了下周安排。

这里有两处状态错误。可以全程纸笔完成，也可以只用虚构材料选择可用工具；不需要付费、真实个人资料、联系任何人或发送真实消息。

## 分步操作

1. 复制[练习模板](starter/exercise.zh.md)，或在纸上照着标题记录。保存 A，找出两处错误。
2. 写一条只针对场地的追问。保存完整 B：自行写纸笔模拟稿，或在选择工具时记录实际修改稿。
3. 摘录 A、B 的场地措辞，判断本轮目标是否通过，以及 B 整篇是否可用；把安排错误保留在问题清单中。
4. 再写一条只针对下周安排的追问，保存完整 C，并标明它是模拟稿还是实际回答。
5. 摘录 B、C 的安排措辞，判断本轮目标。随后从头到尾对照原材料检查 C，排查新增日期、负责人、承诺或已完成动作。
6. 未通过的项目标为未解决，并写下一步如何处理，再对照[一种参考答案](solution/exercise.zh.md)。

## 验收

- 按顺序保留完整 A、B、C 与两条单项追问，完成路径标识准确。
- 每轮都摘录目标修改前后原句，给出通过或未通过及原因；区分目标通过和整篇可用。
- 全文复核覆盖资料已整理、安排讨论过但未定、场地未确认及未经支持的新增内容；剩余错误有下一步。
- 实际回答或自行模拟可以与示例不同，判断应依据自己保存的正文。
