# D5：独立走完整个流程

把请求、草稿、单项追问、核查和复盘独立串起来。小林及原材料均为虚构：小林周五有一小时；公开活动资料已整理；下周安排与同事讨论过但尚未确定；活动场地尚未确认。

可用纸笔、手机备忘录或电脑文档；也可选择自己能使用的助手，但只输入虚构材料。不需要付费、真实个人资料、联系真人或发送真实消息。

## 分步操作

1. 复制[练习模板](starter/exercise.zh.md)，或在纸上照着标题记录；将原材料单独保存。自己写出背景、材料、任务和输出要求：三项建议准备动作，之后是一段简短总结。
2. 保存完整初稿。可以使用课文中的虚构草稿、自行写纸笔模拟，或记录可选工具的实际回答；不要把模拟稿说成某个服务的输出。
3. 选出草稿中确实存在的一项问题，记录原句、依据和一条只针对该问题的追问。保存修改稿，摘录修改前后文字并检查目标是否生效。
4. 将整份修改稿对照原材料。如果仍有其他问题，标为暂不可用，记录一次单独的手动修正或进一步追问；保存结果并重新检查。建议动作不等于已完成的工作。
5. 为重要说法逐条记录依据或依据缺失、判断和处理。没有实际核实的现实信息仍标未知；仅为将来真实需要写出独立来源计划。
6. 给出本次练习的使用决定，记录易错点、发现方式和下次一项具体动作，最后对照[一种参考答案](solution/exercise.zh.md)。

## 验收

- 保存完整请求、完整初稿、一条单项追问和完整修改稿，并准确标注模拟或实际使用。
- 目标检查引用修改前后正文；全文复核覆盖四条给定条件、三项建议、总结和未经支持的新增内容，未解决的问题不标通过。
- 核查记录区分材料支持、冲突、未知和建议；未执行的外部核查标为计划。
- 使用决定和复盘有检查依据；只要记录与判断对应，措辞和发现可以不同。
