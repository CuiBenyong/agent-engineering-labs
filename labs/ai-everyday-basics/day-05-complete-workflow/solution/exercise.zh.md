# D5 参考答案：一次完整的纸笔练习

**虚构示例；下面所有草稿与编辑均为纸笔模拟，不是助手的实际回答，也没有进行外部查询或联系。** 这是其中一种可行过程；只要原材料和检查依据支持，不同措辞或发现也可以接受。

## 原材料

小林周五有一小时；公开活动资料已整理；下周安排与同事讨论过，但尚未确定；活动场地尚未确认。

## 一、完整请求

> 背景：我周五有一小时整理工作。
>
> 材料：公开活动资料已整理；我与同事讨论过下周安排，但安排尚未确定；活动场地尚未确认。
>
> 任务：先列三项准备动作，再写一段简短工作总结。
>
> 输出要求：三项动作写成建议，不编造日期、负责人或已完成动作；未知事项标为「待确认」。

## 二、完整初稿 A：虚构模拟

建议的准备动作：

1. 梳理已整理的公开活动资料。
2. 列出下周安排中需要讨论的问题。
3. 列出需要确认的场地问题。

总结：

> 公开活动资料已整理；活动场地已确认；我与同事讨论了下周安排。

问题：「活动场地已确认」与「场地尚未确认」冲突。另外，总结没有说明讨论过的下周安排尚未确定；先将其单独记入全文复核。

## 三、一次单项追问与模拟 B

追问：

> 请只修改场地状态：材料显示场地尚未确认，请把「活动场地已确认」改为「活动场地尚未确认」，其他文字暂时不变。

完整 B，模拟稿：

建议的准备动作：

1. 梳理已整理的公开活动资料。
2. 列出下周安排中需要讨论的问题。
3. 列出需要确认的场地问题。

总结：

> 公开活动资料已整理；活动场地尚未确认；我与同事讨论了下周安排。

目标检查：A 写「活动场地已确认」，B 写「活动场地尚未确认」，与材料一致，**场地目标通过**。B **整篇暂不可用**：它没有说明下周安排仍未确定。

## 四、单独手动修正并全文复核

不再追问，手动补上遗漏的安排状态，保存 C，标为模拟手动修改：

建议的准备动作：

1. 梳理已整理的公开活动资料。
2. 列出下周安排中需要讨论的问题。
3. 列出需要确认的场地问题。

总结：

> 公开活动资料已整理；我与同事讨论过下周安排，但安排尚未确定；活动场地尚未确认。

| 检查项 | 依据及判断 |
|---|---|
| 周五一小时 | 完整请求写明「周五有一小时」，与材料一致；总结不要求重复背景。 |
| 公开资料 | C 写资料已整理，与材料一致。 |
| 下周安排 | C 写讨论过且尚未确定，与材料一致。 |
| 活动场地 | C 写尚未确认，与材料一致。 |
| 输出形式 | C 有三项建议和一段简短总结；建议不代表已执行。 |
| 新增内容 | C 没有增加活动日期、负责人、承诺或其他已完成动作。 |

## 五、核查依据与使用决定

| 说法或问题 | 依据或缺口 | 判断 | 处理 |
|---|---|---|---|
| B 写场地尚未确认 | 原材料：场地尚未确认。 | 材料支持 | C 中保留。 |
| A 写场地已确认 | 原材料：场地尚未确认。 | 冲突 | 在 B 中改正，在 C 中复查。 |
| B 没有写安排是否已定 | 原材料：讨论过但尚未确定。 | 状态缺失 | 在 C 中手动补充。 |
| 列出场地问题 | 这是建议的下一步，没有声称已执行。 | 建议 | 保留为建议。 |
| 场地费用和开放时间 | 练习材料未提供。 | 未知 | 不声称具体费用或开放时间。 |

外部查询：**未执行**。如果以后确定真实场地，且需要费用或开放时间，可独立寻找其负责运营方的当前官方信息，记录具体场地、适用条件、支持内容和实际查看时间；没有依据前继续保留待确认。

使用决定：C 可以保存为**虚构练习草稿**。它与练习材料一致；安排和场地仍未确认，也不能据此认定现实活动事实。

## 六、复盘

- 易错点：草稿可能把场地写成已确认，或漏写安排尚未确定。
- 发现方式：逐句对照保存的正文和原材料状态，而不只检查修改的那一句。
- 下次行动：写请求前，先把资料已整理、安排未定和场地未确认分别写成三行。
