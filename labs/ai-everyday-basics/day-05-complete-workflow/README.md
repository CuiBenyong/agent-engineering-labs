# D5: Complete the workflow

Independently connect a request, draft, focused follow-up, review, and reflection. Lin and the source material are fictional: Lin has one hour on Friday; public event material is organized; next week's plans were discussed with a colleague but remain undecided; the event venue is unconfirmed.

Use paper, a phone note, or a computer document. An available assistant is optional, and only fictional material should be entered. No paid service, real personal information, real contact, or external message is required.

## Steps

1. Copy [the starter](starter/exercise.md) or reproduce its headings. Keep the source separate. Write your own complete request with context, source material, task, and output requirements: three suggested preparation steps, followed by a short summary.
2. Save a complete first draft. Use the lesson's fictional draft, write a labeled paper simulation, or record an actual response from an optional tool. Do not claim a simulated draft came from a service.
3. Choose one issue that actually appears. Record the original words, source, and one follow-up targeting that issue. Save the revised text and check the target using before-and-after wording.
4. Review the whole revision against the source. If another issue remains, mark the draft not ready and record a separate manual edit or further focused request. Save the resulting text and recheck it. Suggested actions are not completed work.
5. Record each important claim, its evidence or missing evidence, judgment, and action. Mark real-world information not actually checked as unknown, and outline an independent source to consult only if a future real need arises.
6. Record a use decision for this exercise, the error-prone point, how you noticed it, and one concrete action for next time. Then compare with [one possible solution](solution/exercise.md).

## Acceptance

- The record preserves the complete request, complete initial draft, one focused follow-up, and complete revision, with simulation or actual use labeled.
- The target check cites both versions. The full review checks all four given conditions, three suggestions, the summary, and unsupported additions; remaining errors are not marked passed.
- The evidence record distinguishes source support, conflict, unknowns, and suggestions, and labels unperformed external checks as plans.
- The decision and reflection follow from the review. Different wording or findings are acceptable if the recorded evidence supports them.
