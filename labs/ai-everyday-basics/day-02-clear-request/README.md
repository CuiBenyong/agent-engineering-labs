# D2: Compare two requests

Use the same four criteria to compare a vague request and a specific request. Lin and the material below are fictional:

- Lin has one hour on Friday.
- The public event material has been organized.
- Next week's plans were discussed with a colleague but remain undecided.
- The event venue is unconfirmed.

No paid service, real personal information, or message to a real person or organization is needed. A phone note, computer document, or paper is enough. An available assistant is optional; if used, share only the fictional exercise material.

## Steps

1. Copy [the starter](starter/exercise.md), or reproduce its headings on paper. Keep the given statuses visible.
2. Save A, a vague request, and B, a specific request. In B, state context, source material, task, and output requirements; ask for three preparation steps and a short summary.
3. Apply the same four-row comparison to A and B. Count only words actually present in each request. Say whether each criterion is present, partial, or not stated, and cite the wording.
4. If you work on paper, mark the route **not run; paper comparison**. You may add imagined answers only if explicitly labeled hypothetical. Do not describe a prediction as an observed result.
5. If you choose to try a tool, keep both full requests and both actual answers. Note whether the conversations were separate or shared context, then check both answers against the same criteria. Report only what happened in that trial.
6. Check that no real private information or invented date, owner, or completed result is included. Compare with [one possible solution](solution/exercise.md).

## Acceptance

- A and B are both saved, with a comparison using context, source material, task, and output requirements for each.
- B preserves all three material statuses and asks for three proposed steps plus a short summary; unknowns must be marked as needing confirmation.
- The record identifies paper work or an actual trial accurately. A text comparison does not claim an AI was tested or performed better.
- The material is fictional and contains no unnecessary personal information. Different wording is acceptable.
