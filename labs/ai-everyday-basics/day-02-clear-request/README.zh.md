# D2：比较两版请求

用同一套四项标准，比较模糊请求和具体请求。小林和以下材料均为虚构：

- 小林周五有一小时。
- 公开活动资料已整理。
- 下周安排与同事讨论过，但尚未确定。
- 活动场地尚未确认。

不需要付费、真实个人资料，也不需要向真实的人或机构发送任何内容。手机备忘录、电脑文档或纸笔都可以；可选用自己能使用的助手，但只输入虚构练习材料。

## 分步操作

1. 复制[练习模板](starter/exercise.zh.md)，或在纸上照着标题记录。把给定的材料状态放在容易看到的位置。
2. 保存 A 模糊请求和 B 具体请求。B 包含背景、材料、任务和输出要求，请求三项准备动作及一段简短总结。
3. 对 A、B 使用同一张四行对照表。只计算请求实际写出的内容，逐项记录「有、部分有或未写」，并摘录依据。
4. 纸笔完成时标注「未运行，纸笔比较」。如果自行写出预想回答，必须标为假设，不能写成实际观察结果。
5. 如果选择使用工具，保存完整的两版请求和实际回答，记录是分别开新对话还是沿用上下文；用同一标准检查两份回答，只描述本次确实发生的情况。
6. 排查真实私密信息和编造的日期、负责人、完成结果，再对照[一种参考答案](solution/exercise.zh.md)。

## 验收

- A、B 两版均已保存，并分别用背景、材料、任务、输出要求四项标准比较。
- B 保留三项材料状态，要求三项建议动作和一段简短总结，并要求未知内容标为待确认。
- 纸笔与实际试用的记录标识准确；只比较文本时不声称 AI 已运行或表现更好。
- 材料为虚构内容，没有不必要的个人信息。措辞不同也可以通过。
