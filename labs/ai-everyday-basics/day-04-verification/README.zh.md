# D4：为说法寻找依据

将虚构草稿逐条对照给定材料。小林周五有一小时；公开活动资料已整理；下周安排与同事讨论过但未确定；活动场地尚未确认。这些是练习前提，不代表现实中存在一场已核实的活动。

纸笔、手机备忘录或电脑文档都可以，可选用助手。不需要购买服务、提供真实个人资料、联系真实场地或向外发送消息。

## 分步操作

1. 复制[练习模板](starter/exercise.zh.md)。阅读虚构草稿，拆开事实与建议混在一起的句子。
2. 对每个说法，记录材料原句或「未提供依据」，判断为**材料支持、冲突、未知或建议**，再写处理方式。建议不等于已经完成。
3. 纠正下周安排的冲突状态；删除关于费用与开放时间的无依据判断，或明确标为未知。保存保留三项材料状态的修订段落。
4. 为未来真实需求写独立核查计划：如果能确定相关场地和负责方，先识别负责方，再查看其当前官方渠道，并记录适用地点、条件及查看时间。重复询问同一个助手不构成独立来源。
5. 未做的步骤标为**计划，未执行**。不要编造场地、页面、访问、回复、价格或开放时间；无法识别场地或负责来源时，继续保留待确认状态。
6. 最后对照[一种参考答案](solution/exercise.zh.md)。

## 验收

- 草稿的每个部分都有说法、依据或依据缺失、判断及处理；混合句已拆开。
- 分类和理由能区分材料支持、冲突、未知和建议。
- 修订后保留资料已整理、安排讨论过但未定、场地未确认，没有新增无依据内容。
- 独立核查计划写清未来可能使用的来源和需记录的证据；未执行的事不写成已核实。其他有依据的答案也可以。
