# First conversation: ask, revise, check

This is a fictional exercise. Do not upload personal details or confidential work information. You can use paper or an AI assistant.

You have one hour on Friday. You organized public event material, discussed next week's plan without deciding it, and have not confirmed the venue. Ask for three preparation steps and a short summary. Inspect the output for invented names, dates, promises, or completed statuses. Ask for a correction, then check again.

Fill in `starter/request.md` and compare it with `solution/request.md`. Different wording is welcome if the facts and uncertainties remain accurate.

## Practical steps

1. Put the fictional facts in a note or on paper. Mark the venue and plans as undecided.
2. Write a first request, then add the time, facts, task, and constraints.
3. Use a trusted available assistant or the lesson’s fictional incorrect draft. Record which route you used.
4. Point to one status error, revise it, and compare the final wording with the source before saving.
