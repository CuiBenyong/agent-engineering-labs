# 解释、反例与来源核查

题目：一枚公平硬币抛两次，两次结果独立。至少出现一次正面的概率是多少？

待检查文字是课程为练习写的**虚构错误解释**，不是教材原文或真实 AI 输出：

> 至少一次正面就是恰好一次正面。符合的结果是正反和反正，所以概率是 2/4，也就是 1/2。OpenStax 的《Introductory Statistics 2e》第 3 章支持这个结论。

在 `starter/answer.zh.md` 中先写题目假设和“至少一次”的含义，列出四个有序结果，写出正例、负例及能反驳等同说法的反例。独立计算两种事件的概率，并说明为什么能按结果个数相除。再从 [OpenStax 官方入口](https://openstax.org/details/books/introductory-statistics-2e)寻找第 3.1 节和第 3.2 节 Example 3.6，对比原文与引用；若暂时不能查看，就标“来源尚未核验”，不要将引文当证据。

纸笔可以完成计算，不需要实际抛硬币或使用特定 AI 产品。完成后对照 `solution/answer.zh.md`；没有亲自核查来源时仍应保留自己的待确认记录。
