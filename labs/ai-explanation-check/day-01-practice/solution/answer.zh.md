# 一种参考答案

## 定义与结果

- 假设：每次正反面概率均为 1/2，且两次结果独立。至少一次正面包括一次或两次；恰好一次只包括一次。

| 两次有序结果 | 至少一次正面？ | 恰好一次正面？ |
| --- | --- | --- |
| 正正 | 是 | 否 |
| 正反 | 是 | 是 |
| 反正 | 是 | 是 |
| 反反 | 否 | 否 |

- 正例：正反满足至少一次正面。负例：反反没有正面。反例：正正满足至少一次，却不满足恰好一次，因而反驳两种条件等同。
- 四种有序结果在公平且独立假设下等可能，各为 1/4。至少一次正面有三种，概率 3/4；恰好一次有两种，概率 2/4 = 1/2。缺少条件时先确认，改变条件后重新计算。

## 来源与决定

- 本课程编写时核查的教材内容：OpenStax 第 3.1 节用两枚公平硬币讨论恰好一个正面的 2/4；第 3.2 节 Example 3.6 给出至少一个反面的 3/4。本题至少一个正面按上表自行列举为 3/4。
- 判断：虚构解释把两个事件混淆；教材存在，但这些内容不支持“本题至少一次正面为 1/2”。解释和错误归因并非教材原文。
- 个人核查状态：若你还没打开教材，写“尚未亲自核验来源”，不把参考答案当成已完成的来源检查。若 AI 说不确定或来源无法打开，暂停采用该归因，待查证后更新记录。
- 未进行任何抛硬币实验，也没有真实 AI 回复；上述数值属于题设模型的推算。
