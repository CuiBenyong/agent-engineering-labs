# 表达反馈与复练

设想一个虚构小组，你想邀请大家从各自最近读过的一本书开始交流。先用自己的话说两三句，尽快把实际说出的句子写进 `starter/answer.zh.md`，记不准的部分标“不确定”。如果暂时不能出声，可以先写草稿并标“尚未口头练习”，之后补做；不要把草稿当实测记录。

写清听众、目的，以及希望检查的清晰度和结构问题。可以用 AI 文字工具，也可以参考课程自行写出建议；每条都核对是否引用原句。说明采纳、修改、拒绝或待确认的原因，用自己的话调整，再完整说一次并记录真实观察。还没复练就写“尚未复练”，不编造效果。

只用虚构素材，纸笔足够；不需要上传录音、真实姓名或私人对话。参考 `solution/answer.zh.md` 是纸面模拟，不是任何真实学习者或服务的测试结果。
