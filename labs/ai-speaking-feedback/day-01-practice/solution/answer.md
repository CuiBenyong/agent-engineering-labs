# One paper example

This example was invented for the lesson. It is **not a record of actual speech, a recording, or an AI response**. It illustrates how to assess suggestions and does not replace your own first and repeat practice.

## Setup and example words

- Audience: a fictional small group. Purpose: invite them to start by each sharing a book they recently read.
- Example text: I want to say something about reading. If everyone has time, we could talk. I think that would be nice.
- Simulated status: not yet practiced aloud; there is no real listener or recording.
- Request: check whether the desired action and opening invitation are clear. Quote exact words, explain a possible question, offer an optional revision, and do not invent facts, outcomes, or personal experiences.

## Simulated feedback and decisions

| Quoted words | Suggestion and decision | Reason |
| --- | --- | --- |
| If everyone has time, we could talk. | Suggest “If we have time, we can each talk about a book we recently read.” Accept the core idea. | The quote exists; the recently read book comes from the exercise purpose. |
| I want to say something about reading. | Suggest “I want to start a reading discussion.” Accept. | The quote exists; the opening states the invitation more directly, subject to the speaker's own judgment. |
| I think that would be nice. | Suggest adding “This will definitely make everyone love reading more.” Reject. | The quote exists, but the promised effect has no evidence. |

## Revision and repeat practice

- Simulated revision: I want to start a reading discussion. If we have time, we can each talk about a book we recently read. That is where we could begin.
