# 配音与字幕检查练习

为完全虚构的读书会短片做一张纸面计划。三句练习稿是：

1. 翻开一本书，我们聊聊最近的阅读。
2. 虚构读书会短片，只为练习配音和字幕。
3. 你也可以挑一本书，和朋友聊聊。

在 `starter/answer.zh.md` 中选择听众、旁白和字幕需求，给三句安排假设时间轴，写出将来怎样逐句核对发音、同步与无声观看。填写声音、音乐和画面的来源与权限检查。没有真实成片时，所有时间仅为假设，写“尚未试听、尚未验证同步”，不要编造结果；将来有获准素材时，按实际声音调整并复核。

纸笔足够，工具和音视频均可选。未获明确许可不要克隆他人声音，也无需上传私人素材或付费。完成后可对照 `solution/answer.zh.md`，满足同样条件的其他答案也可以。
