# 虚构小店反馈分类练习

用纸笔或电子文档填写 `starter/answer.zh.md`，再对照 `solution/answer.zh.md`。所有句子和编号均为虚构；不需要调用 AI、上传资料或联系顾客。不要向 AI 上传真实客户数据，即使删除姓名，原话和其他细节仍可能识别个人。

## 题设反馈

范围仅为以下六条虚构句子；题设没有真实时间窗、渠道、抽样方法或顾客人数。

| 编号 | 原句 |
| --- | --- |
| F01 | 包装盒角压瘪了。 |
| F02 | 杯子挺轻，拿着方便。 |
| F03 | 价格有点高，不过杯子拿着顺手。 |
| F04 | 包装纸破了，杯柄也松。 |
| F05 | 还行吧。 |
| F06 | 快递比说好的晚了一天。 |

本题定义四个主题：包装指包装盒或材料；商品指杯子的特征、使用感受或商品问题；价格指价格描述；配送指运送或到达过程。一条可有多个主题；主题不明时不猜，记为“待澄清”状态，不把状态算作第五个主题。

## 四步练习

1. 逐条保留原句，填写主题、状态及另列的推断或待确认事项。F03、F04 可多标；F05 不强行分类。
2. 写一条只使用题设虚构句子的可复制请求，要求保留原句、分列推断且人工复核。
3. 核对每个主题涉及哪些编号、各有几条；分开记录六条反馈、主题标记次数和待澄清数量，说明范围及多标签的影响。
4. 列出逐条人工复核方法、真实工作需要确认的权限，以及不能推断的原因、购买意愿或顾客人数。

## 完成标准

包装为 F01/F04，商品为 F02/F03/F04，价格为 F03，配送为 F06，共七次主题标记；五条已有主题，F05 一条待澄清，合计六条。F03 的转折和 F04 的两个现象均保留；不推断运输成因、不声称六条是六位真实顾客。所有材料均为虚构。
