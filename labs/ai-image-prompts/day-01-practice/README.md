# Image prompt practice

Plan a phone announcement illustration for a fictional neighborhood reading event. Complete the starter with the use, subject, setting, style and constraints, then draft the first prompt. You may use a tool you are allowed to access or draw a rough sketch. If you do not generate an image, label the problem as something you expect to check. Write a revision and list checks before public use. Compare the solution; other answers that meet the brief are welcome.

You do not need to upload real people's photos, private information or unauthorized images, and no payment is required.
