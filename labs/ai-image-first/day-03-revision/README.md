# D3 practice: One revision and a comparison

## Steps

1. Select your D2 image or sketch and record the version, original prompt and generation status.
2. Name one concrete issue and the book, tea, composition and space you want to retain.
3. Write one main requested change. Choose local editing or a complete-prompt regeneration.
4. On paper, mark a proposed selection or write the complete fallback prompt. If using a tool, check permissions and cost first.
5. Compare the issue, subject, space, accidental writing and marks; mark them pending when no result exists. Decide what to keep or check next.

## Acceptance

The baseline and main change are clear; the chosen route is actionable; the comparison and next action are recorded; predictions and observations remain separate. The solution is hypothetical.
