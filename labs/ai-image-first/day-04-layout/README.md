# D4 practice: Reading-event layout

## Steps

1. Choose a social image or poster, state where it would be viewed, choose a practice shape and mark an inner margin.
2. Sketch or import a background you may use, with book and tea by the window and a simple area above.
3. Enter “Neighborhood Reading Event” and “Saturday afternoon” yourself. Both are fictional practice text, not a real announcement.
4. Check the words character by character; preview at phone size or hold the paper farther away. Record any adjustment.
5. If exporting, check format and cost first, then reopen the file. Label paper work as not exported.

## Acceptance

Include purpose and shape rationale, accurate fictional text, readable subject and words, honest preview/export status, and unresolved conditions. The solution is a paper example.
