# 练习说明

请为虚构读书会设计一张竖版插图：窗边桌上有一本书和一杯茶，上方留白，不含人物、标志或文字。先在 starter 中写出主体、场景、风格和用途，再尝试描述一次修改并列出三项使用前检查。有可信、合适的工具时可以试作；没有工具时用纸笔完成。不要输入真实个人资料或上传未获授权的图片。

完成后对照 solution；符合要求的不同答案同样可以。

## 操作步骤与验收

1. 复制 starter 中的空表到纸上或自己的笔记，写明主体、场景、风格和用途。
2. 写第一版完整提示词；在纸上画一个竖矩形，标出书、茶和上方留白。
3. 若自愿使用已核对且有权使用的工具，先查看当前价格、次数和权限，再自行决定是否提交；否则只记录预计要检查的问题。
4. 写出一项修改并对照第一版；将实际观察与纸上预测分开。
5. 列出费用、隐私、素材权利及标识中需要确认的事项。没有生成或保存时如实标注。

验收：两版请求与一项区别可见；有实际观察或清晰标注的预测；至少三项使用前检查；无真实个人资料。参考答案是示例，并非已经运行的工具结果。
