# Practice

Plan a portrait illustration for a fictional reading event: a book and tea on a table by a window, clear space at the top, no people, logos, or text. In the starter, identify the subject, setting, style, and use; propose one revision and three checks before use. Try an appropriate trusted tool if you have one, or work on paper. Do not submit private information or unauthorized photos. Compare with the solution; other accurate answers are welcome.

## Steps and acceptance

1. Copy the starter fields onto paper or into a note; identify subject, setting, style and use.
2. Write a complete first prompt. Draw a portrait rectangle and mark the book, tea and clear space above.
3. If you choose to use a verified tool you are allowed to use, review its current price, attempts and permissions before deciding whether to submit. Otherwise record issues you would inspect.
4. Write one revision and compare it with the first request. Separate actual observations from paper predictions.
5. Record checks for cost, privacy, source permissions and disclosure. State honestly when no image was generated or saved.

Acceptance: both requests and their difference are visible; there is an observation or an explicitly labeled prediction; at least three pre-use checks are listed; no real personal data is included. The solution is an example, not a report of a tool run.
