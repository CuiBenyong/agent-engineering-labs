# D3 实验：让模型当裁判，再把裁判本身考一遍

今天给 `evalkit` 加一个**模型型评分器**，然后立刻做一件更重要的事：
**把这个裁判本身拉去考试**，用两个实验判定它到底能不能用。

跑完这一天，你手里会有一份能回答这个问题的报告：

> 这个裁判有多大的位置偏好？它和人工标注的一致性够不够拿去拦合并？

## 为什么裁判是离线的

本课的重点不是「怎么调模型当裁判」，而是**怎么把裁判本身考一遍**。
考试需要对照组：位置偏好调成 0 之后，那个数字应该回到多少？

真实模型给不了你这个对照组——你调不动它的偏差，它的偏差每次还都在变。
所以这里写了一个**带可配置偏差的离线裁判**：它真的偏向排在前面的答案、
真的偏向更长的答案、真的偏袒署名自家的输出，三个系数写在 `DEFAULT_JUDGE` 里。
把它们调成 0，你就有了一个理想裁判。

接真实网关时只要把 `scoreByRubric` 换成一次 `/v1/chat/completions` 调用，
本实验其余部分（量表结构、交换实验、kappa 计算、准入阈值）**原样可用**。

## 今天的练习

### 练习 1 —— `src/graders/judge.ts` 的 `scoreByRubric`

按量表给一条答案打分，并且**把三部分分开返回**：量表基础分、长度偏好加分、自评偏好加分。
分开返回不是洁癖：校准报告要能说清「这 0.58 分里有 0.25 是长度送的」，
不然你没法判断该修量表还是该换裁判。

### 练习 2 —— `src/graders/calibration.ts` 的 `runSwapExperiment`

同一对答案正反各评一次，按下面这条**全课固定**的规则合并：

- 两轮都判 a 赢 → a 赢
- 两轮都判 b 赢 → b 赢
- **两轮结论矛盾（翻转）→ 判平**，不是随机取一个
- 任意一轮判平 → 判平

最容易写错的是第二轮：参数顺序换了，所以 `judgePair` 返回的 `first` 指的是 **b** 赢。
写错之后翻转率会变成 0，而且不会报错——自检的第 2、4 条就是防这个的。

### 练习 3 —— `src/graders/calibration.ts` 的 `cohenKappa`

```
po    = 两人结论一致的比例（就是准确率）
pe    = 各自的标签分布下随机也能一致的比例
kappa = (po - pe) / (1 - pe)
```

两个退化情形必须处理：`n` 为 0，以及 `1 - pe` 逼近 0（两人都把所有样本判成同一类）。
后者 kappa 在数学上无定义，**返回 0**——「无定义」在报告里必须表现为
「这个裁判没提供信息」，绝不能表现为满分。

MOCK=1 pnpm start -- --unbiased   # 把三种偏差调成 0，看对照组

## 手动验收清单

自检全绿**不等于**做完了。下面几条要你亲眼看一遍：

- [ ] `MOCK=1 pnpm start` 的第 2 段，**前排胜率是 70.8%**，而不是 50%。
      这就是位置偏好被量出来的样子。
- [ ] 同一段的翻转率是 **41.7%**。想清楚它的含义：
      如果你只评一轮，这 12 条结论里有 5 条是**位置决定的**，而报告不会告诉你是哪 5 条。
- [ ] 换成 `--unbiased` 再跑一次，前排胜率**正好回到 50.0%**、翻转率回到 0。
      两次都要看——只看有偏那次，你没法区分「量出了偏差」和「实验代码恒定报告有偏差」。
- [ ] 第 3 段：同一段文字，署名自家 0.57 通过、署名别家 0.47 不通过。
      自评偏好最难受的形态就是这个——它不改变排序，只改变过不过线。
- [ ] 第 4 段的两行数字并排读：
      本裁判准确率 86.7% / kappa 0.259，无脑全判通过准确率 90.0% / kappa 0.000。
      **那个什么都不看的裁判，准确率更高。** 如果你的准入标准是准确率，你会选中它。
- [ ] `--unbiased` 那次第 4 段，kappa 从 0.259 升到 0.714，准入判定从 ❌ 变 ✅。
      注意准确率只从 86.7% 升到 93.3%——**同一个改进，kappa 的分辨率高得多**。
- [ ] 打开 `src/tasks/day03.ts`，读 `cal-28` 那条 219 字的车轱辘话。
      它通篇没说这单到底退了没有，人工判不合格，裁判判通过。这就是长度偏好的成本。
- [ ] 打开 `cal-26` 与 `cal-27`：人工判合格，裁判判不合格。
      这两条**不是偏差，是量表的漏洞**——换了个同义说法判据就抓不住了。
      两类错误的修法完全不同：偏差要换裁判，漏洞要改量表。

## 两组要记住的数字

|              | 准确率    | kappa     | 准入（>= 0.6） |
| ------------ | --------- | --------- | -------------- |
| 带偏差的裁判 | 86.7%     | 0.259     | ❌             |
| 无脑全判通过 | **90.0%** | **0.000** | ❌             |
| 偏差调成 0   | 93.3%     | 0.714     | ✅             |

校准集是 30 条里 27 条合格，**故意不均衡**。
不均衡是准确率骗人的前提条件，把它「修」成 15 : 15 这个陷阱就演示不出来了——
而线上送去人工标注的样本，本来就大多数是正常的。
