## 动手前先记住这五条硬规则

1. **一页。** 不是「差不多一页」，是打印预览确认过的一页。
2. **反向时序。** 最近的排最前，每一段内部也一样。
3. **每条要点以动词开头**，用过去式：`Built` / `Designed` / `Reduced` / `Cut` / `Shipped` / `Instrumented`。
4. **全文不许出现 `Responsible for`。** 它描述的是职责范围，不是你做成的事。
   同理不要用 `Helped with`、`Worked on`、`Participated in`。
5. **不放照片、年龄、性别、婚姻状况、身份证号、籍贯。**
   这不是审美差异——很多国家的招聘流程会主动规避这些信息以降低歧视风险，
   带上它们反而会让 HR 为难。中文简历放照片是常见做法，英文版一律去掉。
