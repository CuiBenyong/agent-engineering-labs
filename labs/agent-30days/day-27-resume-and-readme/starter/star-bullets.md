# STAR 简历要点（待填）

> 一句话公式，三条都套它：
> **在（约束）下，为了（目标），我（具体技术动作），把（指标）从 X 改善到 Y。**
>
> 纪律只有一条：**拿不出 Y 就不要写这一条，换一条能量化的。**

## 填之前先读这一段

- 这三个是**学习项目**。简历上标成「个人项目」或「课程项目」，放在项目经历一栏，
  **不能混进工作经历**。
- 每个数字都必须是**你自己在本地跑出来的**，并且**注明测量条件**（几个副本、什么模式、
  多大的输入）。不要写「支撑百万 DAU」这种没跑过的数——追问两句就穿帮，而且作废的
  不只是这一条，是你其余全部的真数字。
- 数字去哪找：对应那一天实验的 `MOCK=1 SELFTEST=1 pnpm start` 输出，以及那一天
  `README.md` 的「验收标准」一节。**X 和 Y 通常一个在 starter 的输出里、一个在 solution 的输出里。**
