# 模板二：客服 Agent

> 一句话主线（开口第一句就说）：**任何一通会话最后只能落到三条出口之一——自助解决、转人工、留工单。**
> 面试官想听的不是「我接了个知识库」，是「你怎么保证不把用户困在机器人里」。

时间盒：澄清 5' / 估算 3' / 草图 8' / 深入 15' / 权衡 5'。

- 日活与并发会话数是多少？

- 知识库有多大、多久更新一次？（决定检索是不是本题重点）
