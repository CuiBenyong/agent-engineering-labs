# D26 实验：3 份答题模板

> 目标：把 D8–D25 学过的零件重新组织成四份可以照着讲的系统设计答题模板（Agent 平台、客服 Agent、多租户、成本控制），每一份都带五步时间盒，练到 15 分钟内不看稿讲完。今天的产出是文档，不是程序。

## 你会学到

- 写一份 Agent 平台系统设计的答题模板（含架构图要点）
- 写一份客服 Agent 系统设计的答题模板
- 写一份多租户设计的要点清单
- 写一份成本控制设计的要点清单
- 找人（或自己录音）模拟讲一遍，检查是否 15 分钟内讲得清楚

## 目录

- `starter/`：四份挖空的模板，骨架、小标题、提示问句都写好了，待填处是 `> TODO：` 引用块
- `solution/`：用本课三个仓库（`agent-service`、`mini-koda`、`mini-multi-agent`）填好的示范样例

两个目录里的文件名一一对应：

| 文件                        | 对应的题            | 一句话主线              |
| --------------------------- | ------------------- | ----------------------- |
| `agent-platform.md`         | 设计一个 Agent 平台 | 无状态执行 + 有状态编排 |
| `customer-support-agent.md` | 设计一个客服 Agent  | 三条出口                |
| `multi-tenant.md`           | 多租户怎么隔离      | 三层隔离                |
| `cost-control.md`           | 成本失控了怎么办    | 五层手段，从便宜到贵    |

## 怎么用

这一天没有代码，所以**不需要** `pnpm install`、不需要 `MOCK=1`、也没有自检脚本。

1. 先通读 `solution/` 的四份样例，看清楚每一份是怎么把五步填满的。
2. 回到 `starter/`，把每个 `> TODO：` 引用块换成**你自己项目**的内容——`solution/` 是参照物，不是答案。
3. 打开手机录音，对着 `starter/agent-platform.md` 讲一遍，掐表 15 分钟。
4. 回放录音，用下面的验收标准逐条对。讲不顺的那一段单独再练三遍，不要从头重讲整篇。

## 验收标准

1. `solution/` 四份模板通读一遍后，对着 `agent-platform.md` 讲一遍并录音，**15 分钟内讲完且全程不看稿**。
2. 回放录音，五步的时间盒逐一对得上：澄清不少于 3 分钟、估算里报出了 0.0006 和 900 这两个数**并说得出算式**、草图四块齐全。
3. 对着 `customer-support-agent.md` 讲，能在 60 秒内不看稿说清三条出口和四条量化的转人工判据。
4. `starter/` 四份模板里的每一个 `TODO` 引用块都换成了你自己项目的内容，全文搜 TODO 零命中。
5. 找一个人（或用录音自评）随机点名三个「深入包」里的任意一个，你能不看稿讲满 5 分钟。

## 常见坑

1. **把模板背成台词。** 模板是骨架不是稿子，面试官一打断你就回不到原位。练的方式是每次讲的措辞都不一样，只有结构不变——能用三种说法讲同一段，才算真的会了。
2. **估算那一步只报结果不报算式。** 写模板时就把算式写进去（2000 输入 + 500 输出 → 0.0003 + 0.0003 = 0.0006 美元每轮），讲的时候一边写一边说。面试官插的那句永远是「这个数怎么来的」。
3. **四份模板互相串台。** 三条出口只属于客服 Agent，三层隔离只属于多租户。串了台就说明你在背词而不是在推导。
4. **只填 `solution/` 不改成自己的。** 示范样例用的是本课三个仓库，你简历上的项目细节不一样，直接照搬会在第一个追问就露馅。
