# Sample: Compare the source and revision

Discussion is not approval. The venue still needs to be asked about; it is not booked. The image is in progress, not necessarily nearly complete. The date is undecided, not next week.

Corrected version: The reading event has been discussed; the venue still needs to be asked about, the promotional image is being made, and the date has not been decided.

Each clause maps to a source status without adding approval, a booking or a completion time.
