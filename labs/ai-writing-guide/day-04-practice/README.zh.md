# 场地询问邮件

虚构材料：考虑举办社区读书交流，邀请居民分享喜欢的书；日期、场地是否可用及费用尚未确认，没有真实联系人或答复。

可以使用纸笔、手机或电脑文字笔记；AI 助手可选，真实发送不是练习的一部分。

1. 列出收件人、时段、费用及使用条件等待确认事项。
2. 写未发送的询问邮件：主题、活动背景、两三个问题、礼貌结尾。不要写真实地址或承诺预订。
3. 单独标注假设：对方说“下周部分时段可能可用，费用需核实”。起草追问具体时段与费用的回复。
4. 解释假设不是实际回复，检查邮件并保存，不发送。

先填写 starter/answer.zh.md，再与 solution/answer.zh.md 比较。不同措辞只要有依据、状态准确即可。
