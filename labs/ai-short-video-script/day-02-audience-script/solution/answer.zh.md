# 一种参考答案

受众是对阅读交流感兴趣的成年人；目的为介绍阅读交流。日期、地点和报名方式待确认。开头：“想和别人聊聊最近读过的书吗？”后接：“读书会可以从一本书、一段感受开始。”“这里是虚构练习，具体形式待确认。”“时间、地点和报名方式待确认。”四句可分别配四镜头。朗读时间由学习者自己记录；若超时，可删去重复词后再读，不应编造计时结果。分享形式用于真实活动前也须确认。

这是供核对的虚构示例，其他满足条件的答案也可以。实际使用前仍须核实事实和许可。

备选开头：“最近读到一句话，想找人聊聊吗？”选择“想和别人聊聊最近读过的书吗？”是因为直接说明阅读交流。修改例：“本周六来读书会分享，你一定能交到朋友”改为“想和别人聊聊最近读过的书吗？”删除了未确认的日期与不能保证的结果。读者应记录自己实际朗读的秒数，或标记未计时。
