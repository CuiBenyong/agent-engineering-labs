# 受众、开头与口播

## 任务

把受众和目的写成任务卡；区分已知与待确认事项；写一个开头和四段口播；朗读计时并至少修改一句。

## 操作

1. 打开 starter/answer.zh.md，复制到自己的纸面或本地笔记，填写每一项。
2. 仅使用本课虚构案例：成年人、阅读交流、手机与桌面素材；日期、地点和报名方式待确认。
3. 可选用文字助手整理想法，也可以全部手写；不要上传私密资料，也不需要付费、拍摄或发布。
4. 对照 solution/answer.zh.md 检查事实、时长及使用权限，记录与参考答案不同但有理由的选择。
5. 写明练习状态和未完成的验证；不要把计划写成已经发生的事。

## 验收

完成 starter 各项，能解释一个修改及仍需确认的事项；涉及时间或阅读速度时以自己实际测试为准。
