# 小店客服事实卡与转人工练习

“木禾小店”、顾客问题和事实卡均为虚构，没有真实政策或顾客数据：

- F1：周一至周五 10:00–18:00 可以到店自取；其他时段未说明。
- F2：提供纸袋包装；是否收费和其他包装未说明。
- H1：本练习假设退款、过敏、订单争议及事实卡未覆盖的问题由员工处理。这不是所有商家通用的分流规则。

五条虚构问题：

1. C1：“什么时候可以到店自取？”
2. C2：“纸袋要收费吗？”
3. C3：“我想退款，什么时候到账？”
4. C4：“我对花生过敏，这个食品能吃吗？”
5. C5：“我的商品有问题，我认为处理不公平。”

填写 `starter/answer.zh.md`：每条写分类、依据、待审草稿和待确认事项；为需要人工的问题写最小交接记录，注明实际尚未转交。检查不编造政策、价格、结果或时间，不含真实顾客资料，也不声称消息已发送。完成后对照 `solution/answer.zh.md`，用自己的话表达也可以。

验收标准：C1 的草稿有 F1 支持；C2–C5 按 H1 交人工且保留各自的未知事项；至少一份交接写明问题、依据、未知项、接手角色及“待转交”；所有草稿均未发送。纸笔即可完成，不需要登录工具、上传信息或联系任何人。
