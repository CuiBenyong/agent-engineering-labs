## 工作流

1. 跑 `scripts/check_header.py <文件路径>`，它会把每一列的名字与推断类型打成 JSON 输出到标准输出。
2. 逐列对照约定：必需列一个都不能少，类型不符要指出是哪一行第一次不符。
3. 有任何一列不合格就停下来报告，**不要**顺手改数据文件。

## 坑

- 第一行不一定是表头，先看有没有 BOM 或者注释行。
- 数字列里混进一个空字符串会让类型推断退化成字符串，报告里要说清是哪一行。
