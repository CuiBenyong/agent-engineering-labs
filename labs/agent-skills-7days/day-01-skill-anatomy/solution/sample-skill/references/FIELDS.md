# 字段与状态码对照（示例）

这份文件是「按需读取」的示范：它只在变更条目里出现字段名或状态码时才有用，
所以不放在 SKILL.md 正文里，而是切出来放在 references 下。

| 字段      | 类型    | 说明                   |
| --------- | ------- | ---------------------- |
| `orderId` | string  | 订单号，全局唯一       |
| `status`  | enum    | 见下表                 |
| `amount`  | integer | 金额，单位是分，不是元 |

| 状态码 | 含义           | 调用方该怎么办   |
| ------ | -------------- | ---------------- |
| 200    | 成功           | 正常解析         |
| 409    | 订单状态已变更 | 重新拉一次再重试 |
| 422    | 参数校验不通过 | 不要重试，改参数 |
