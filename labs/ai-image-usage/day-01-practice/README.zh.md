# AI 图片用途与授权证据表

小岚和“山边小物”手作店均为虚构。她计划做一张帆布袋推广图，在网店和朋友圈展示两周；地域及是否交给别人投放尚未确定。她没有选择具体生成模型，也没有生成图片。朋友发来的参考照片中有可辨认的人物和衣服上的标志，朋友只说过“可以拿去看看”，没有明确允许上传、修改或广告使用。这个练习中的照片、店铺与工具页面都不存在。

填写 `starter/answer.zh.md`，分别记录计划用途、工具账号和功能、照片、人物、标志和 AI 标识。每一项写出已有依据、状态和下一步；没有依据就写“待确认”。给出是否上传及发布的决定，并说明改用纸上自绘的虚构背景后还有哪些检查。完成后对照 `solution/answer.zh.md`；不要求逐字一致。

验收标准：

1. 写明网店、朋友圈和两周是计划用途，标出地域及转交投放尚未确定。
2. 将工具条款、照片许可、人物和标志分别列出，指出这句聊天不证明广告授权。
3. 标明适用标识需要按地区和平台核对，不能用配文代替其他权限。
4. 因证据不足而暂缓上传和发布，并说明替换参考图后的复查事项。

纸笔即可完成，不需要登录、购买、上传真实照片或实际发布。参考答案不是对真实项目的授权。
