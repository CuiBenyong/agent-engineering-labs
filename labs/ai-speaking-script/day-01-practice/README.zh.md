# 口播稿与试读记录

用一场完全虚构的社区共享书架活动练习。已知：周六下午三点到四点在社区多功能室举行；参与者可以自愿带一本书来分享，也可以空手来；带来的书不需要送给别人。没有给出具体日期、地址、费用、报名方式或联系人。不要把它当作真实活动发布。

为可能对阅读感兴趣的社区居民写口播，总上限 60 秒，语气像和邻居说话。打开 `starter/answer.zh.md` 填写事实卡、空缺和第一版。用钟表自然读两次，记下实际秒数和卡顿位置；删改后完整再读并计时。把不包含在朗读里的片头片尾另算，再核对事实、隐私和授权。如果暂时不能出声或计时，先完成写稿并标记“尚未试读”，之后补做，不要虚构秒数。

纸笔足够；AI 文字工具可选。不要上传真实个人资料或未经授权的材料。完成后比较 `solution/answer.zh.md`；答案不唯一，参考答案也没有替你证明时长。
