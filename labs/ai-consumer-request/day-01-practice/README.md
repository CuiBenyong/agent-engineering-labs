# Fictional after-sales request preparation

Complete `starter/answer.md` on paper or in a document, then compare `solution/answer.md`. The product, dates, photo and seller are fictional. No AI call, seller contact or message sending is required. Do not upload real order numbers, addresses, phone numbers, chat records, screenshots or images.

## Scenario facts and request

- S1: one ceramic mug was ordered on 8 October 2030.
- S2: the package was received on 10 October 2030.
- S3: when opening it on 11 October 2030, the person saw one crack where the handle joins the cup; the mug has not been used.
- S4: suppose a photo was taken after opening that shows the crack at that location; no real image file exists.
- S5: the seller has not been contacted and has not responded.
- The scenario's consumer wants first to ask whether the same model can be replaced. If not, they want to ask whether a refund can be requested and about materials, steps, possible costs and estimated time. The cause, seller policy and outcome are not supplied.

## Imaginary flawed draft

“When it arrived on 10 October, the carrier had already broken the cup. The seller agreed to a full refund within seven days. My order number and phone are attached; please handle it immediately.” This was written for practice, not observed as model output or a seller reply.

## Four steps

1. List the timeline, observation, hypothetical material, guesses and unknowns separately. State what S4 might show and what it cannot prove.
2. Identify the flawed draft's observation date, causal claim, refund promise and attachment problems.
3. Write a reusable request using only fictional material, then an unsent consumer message asking about replacement first and, if necessary, refund and process details.
4. List facts, privacy and status checks for the person; explain that there was no real upload, seller response or legal conclusion.

## Completion criteria

Dates and the observation are represented accurately. Unknown cause and seller response are not invented. Replacement and refund are consumer questions, not seller promises. The imaginary photo is not described as submitted. The message is unsent and contains no real personal information.
