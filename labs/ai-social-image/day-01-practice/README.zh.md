# 朋友圈配图选择与检查

小满是虚构人物，她只打算分享：“周末准备整理旧书，看看哪些可以继续读。”她没有组织活动，也没有公布活动地点、活动时间、价格或联系方式。候选 A 是像照片一样的街角书店，门上有店名，角落写着“周日免费交换”与一串模糊数字；候选 B 是书堆和布袋的简洁插画，没有可辨认的店名、人物或活动文字。两张都只是描述，没有实际图片。

填写 `starter/answer.zh.md`：选择候选图并说明是否改变了分享含义；画 B 并用纸框模拟两种遮挡；填写事实、隐私、图片权限和标识检查；给出继续、修改后复查或暂缓的决定及下一步。把假设标为“预计检查”，把没有证据的事项标为“待确认”。完成后对照 `solution/answer.zh.md`，不必与参考答案逐字相同。

验收标准：

1. 说清选择理由，并指出候选 A 的未经证实的暗示。
2. 记录纸框模拟的潜在遮挡，明确它不是朋友圈的实测预览。
3. 区分已给定事实和未确认内容，分别列出隐私、权限和标识的处理。
4. 最终决定与证据一致，并写出未确认事项及下一步。

只用纸笔即可完成；可选的工具体验以当前界面为准，不要求付费、上传真实照片或发布朋友圈。
