# 练习：从会议材料到未发送的周报

使用纸笔、文档或获准的 AI；所有材料虚构，不需真实会议记录或邮箱。

## 已知材料

- N1：小林完成海报初稿，整理两份公开场地资料；活动时间和场地未确定，D1 时报名人数未统计。
- M1：周三讨论时，小林负责周五核对场地可用性。
- M2：小周负责下周一提供已批准的宣传文字。
- M3：活动时间讨论过，具体日期没有决定。
- M4：场地尚未确认；此前收集两份公开场地资料。
- M5：记录没有写已批准预算，也没说明宣传文字是否已经批准。
- M6：有人提议入口放指示牌；没有写是否采纳、负责人或期限。

## 步骤与验收

1. 在 starter 中将材料分成讨论、已决定的行动、待确认；每项标来源。
2. 填写任务、负责人、相对期限、来源和状态；M6 保留为提议，不猜名字。
3. 用 starter 的请求写周报。对照原文找出“场地已预订”“预算未批准”等超出证据的说法。
4. 与 solution 比较；保留具体日期未知、两项结果未知，周报不发送。
